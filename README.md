# Emirates Crew Portal

A responsive crew operations portal concept built with React and Vite.

## Local development

```bash
npm install
npm run dev
```

## Roblox authentication integration

The current `Jakele7` identity is a UI placeholder. Replace it with your authenticated Roblox user payload once the backend OAuth/login flow is available. Keep OAuth secrets server-side and return only the display name, avatar URL, and authorised crew role to the client.
